# Task 1: Landing Page

A clean, modern, and responsive landing page built as part of the Oasis Infobyte Web Development & Designing Internship.

## 🌟 Features
* **Header & Navigation:** Smooth navigation menu with quick links.
* **Hero Section:** Engaging headline with a clear Call-to-Action (CTA) button.
* **Responsive Design:** Fits seamlessly across mobile, tablet, and desktop screens.
* **Styling:** Clean UI layout with balanced contrast and modern typography.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and content markup.
* **CSS3:** Custom styling, Flexbox layout, and media queries for responsiveness.
